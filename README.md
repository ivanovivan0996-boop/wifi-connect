# WiFi Connect

Android-приложение для обнаружения устройств в локальной Wi-Fi сети.

## Первая версия
- Определение IPv4-подсети.
- Поиск устройств с доступными TCP-службами.
- Отображение IP-адресов и найденных портов.

Важно: открытый порт не означает, что файлы или удалённое управление доступны. Для этого нужны включённые службы и разрешённая авторизация на целевом устройстве.

## Сборка
GitHub Actions автоматически собирает debug APK при push в main.
